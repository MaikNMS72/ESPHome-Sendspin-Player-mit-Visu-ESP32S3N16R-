# 3D-Druckdaten

Dieser Ordner enthaelt die 3MF-Dateien fuer das Gehaeuse des Sendspin
Gartenhaus ESPHome Players.

## Dateien

| Datei | Beschreibung |
| --- | --- |
| `gehaeuse-esp32s3n16r8-lcd-encoder-button-body-fillet.3mf` | Hauptgehaeuse fuer ESP32-S3 N16R8, LCD, Encoder und Tasten |
| `deckel-fillet001.3mf` | Deckel fuer das Gehaeuse |
| `encoder-knopf-body-fillet.3mf` | Drehknopf fuer den Encoder |

## Hinweise

- Format: 3MF
- Die Dateien wurden mit GitHub-freundlichen Namen ohne Leerzeichen und Umlaute abgelegt.
- Vor dem Druck bitte Ausrichtung, Stuetzstrukturen und Materialeinstellungen im Slicer pruefen.
